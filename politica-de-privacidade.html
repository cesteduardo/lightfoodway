Política de Privacidade

Como a Light Food Way trata os dados pessoais de quem navega no site.

Documento pendente de redação jurídica. O texto abaixo é apenas a estrutura mínima exigida pela LGPD — deve ser revisado pelo jurídico antes da publicação.

1. Quais dados coletamos

Dados de navegação (cookies e métricas de uso) e, quando você utiliza a busca por localização, a posição aproximada informada pelo seu navegador — usada apenas para exibir as unidades mais próximas e nunca armazenada.

2. Como usamos os dados

Para melhorar a experiência do site, medir audiência e direcionar você à unidade mais próxima.

3. Compartilhamento

Não vendemos dados pessoais. O site utiliza a API pública ViaCEP para converter CEP em cidade e pode direcionar você a canais de terceiros (WhatsApp e iFood), que possuem políticas próprias.

4. Seus direitos

Você pode solicitar acesso, correção ou exclusão dos seus dados pelo e-mail contato@lightfoodway.com.br.
